# Home Browser
Home Browser is an addon for Raidcore Nexus dedicated to community Homestead/Guild Hall browsing and downloading in Guild Wars 2. From this tool, users have direct in-game access to some of the top GW2 community layout sharing sites, like gw2.homes.

### First Launch
When you first launch, the browser is going to take a short moment to do an initial cache, bringing you basic browsing details and thumbnails.

### User Experience
This tool couldn't be easier. Browsing just like the web interfaces, also allowing a simple list view. Select the listing you would like to look at and a new details window will provide you with all of the basic information, including a required decorations list. If you provide valid API key, it will even mark the decorations you are missing. You can even jump directly to the dedicated page for the listing as well as download directly to your local homestead and guild halls folders for quick access.
